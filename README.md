# 👥 HR Employee Attrition & Workforce Analytics

## 📌 Project Overview
This project analyzes employee attrition using MySQL and the IBM HR Analytics Employee Attrition dataset. The objective is to identify employee turnover patterns, salary trends, job satisfaction and factors influencing employee retention.

## 🛠️ Tools & Technologies
- MySQL
- SQL
- PowerPoint
- IBM HR Analytics Dataset

## 📊 Key Performance Indicators

| Metric | Result |
|---|---:|
| Total Employees Analysed | 1,470 |
| Employees Left | 237 |
| Overall Attrition Rate | 16.12% |
| Sales Department Attrition | 20.63% |
| Highest Job Role Attrition | 39.76% |

## 🔍 SQL Concepts Used
- Data Cleaning and Validation
- Duplicate and NULL Value Checks
- Aggregate Functions
- GROUP BY and ORDER BY
- CASE WHEN
- Subqueries
- Correlated Subqueries

## 💡 Key Business Insights

1. Overall employee attrition rate was 16.12%.
2. Sales department recorded the highest attrition rate at 20.63%.
3. Sales Representatives had the highest job-role attrition at 39.76%.
4. Employees working overtime had a 30.53% attrition rate compared with 10.44% for employees not working overtime.
5. Employees with low job satisfaction had a higher attrition rate.
6. Average monthly income of employees who left was $4,787 compared with the company-wide average of $6,503.

## 📁 Project Files

- `HR_Employee_Attrition_Project.sql` – SQL queries and business analysis.
- `HR_Attrition_Analysis.pptx` – Presentation of findings and recommendations.

## 🎯 Project Objective
To analyze workforce data, identify major employee attrition factors and provide actionable insights that can help organizations improve employee retention and workforce planning.
